# Experiment Log

Track design experiments. Insights feed Decision Log and prompt Improvement Logs.

**Owner:** named Owner per experiment · portfolio-producer (index hygiene)  
**Authoritative:** yes for experiment outcomes  
**Path:** `portfolio-os/governance/Experiment_Log.md`

---

## How to use

1. ID: `E-NNN`
2. Write a falsifiable Hypothesis before running
3. Status: `Planned` · `Running` · `Complete` · `Aborted`
4. On Complete: Result · Insights · Follow-up (may create `D-` or `A-` items)
