## Reference Families

Use these families to avoid overfitting to the initial archival and Indian vernacular board. Keep the original baseline available, but search broadly when the project asks for it.

- Culture and vernacular graphics: street signage, packaging systems, matchbox labels, devotional prints, transit tickets, public notices, festival posters, hand-painted lettering.
- Retro technology: early computer interfaces, oscilloscope displays, terminal typography, calculator keys, synth panels, broadcast graphics, hardware manuals.
- Scientific and technical diagrams: lab notebooks, botanical plates, patent drawings, engineering schematics, weather maps, circuit diagrams, anatomical charts.
- Aerospace and mission-control systems: telemetry dashboards, spacecraft panels, launch-room consoles, orbital diagrams, checklist interfaces, avionics labeling.
- Japanese graphic systems: transit maps, magazine grids, packaging, signage, game manuals, typographic posters, information-dense catalog layouts.
- Gaming and interface archaeology: arcade HUDs, console menus, strategy game dashboards, inventory screens, save/load systems, pixel-era UI frames.
- Industrial design: instrument clusters, machinery labels, product exploded views, tool cases, safety markings, control panels, material swatches.
- Editorial systems: newspaper grids, magazine openers, footnotes, captions, indexes, pull quotes, atlas pages, archival catalogs.
- Cinema and title design: film titles, intertitles, lobby cards, subtitles, montage graphics, end-credit systems, poster typography.
- Architecture: tile grids, facade rhythm, window systems, thresholds, wayfinding, floor plans, material transitions, ornamental structure.
- Information visualization: statistical atlases, transit diagrams, dense dashboards, annotated charts, timelines, maps, decision trees.
- Experimental interaction: gestural interfaces, spatial UI, kinetic typography, generative layouts, playful state changes, narrative onboarding.
- Material and print processes: risograph, letterpress, screen print, halftone, photocopy, newsprint, embossing, foil, ceramic glaze, metal wear.

## What To Capture

For each useful reference, record:

- Source or link.
- Visual traits worth keeping.
- What product/UI context it could inform.
- What to avoid copying too literally.

## Evolving The Board

Keep separate buckets:

- Core: references that should influence most Hypermind work.
- Wildcards: experimental, strange, or unresolved ideas worth protecting.
- Contextual: references useful only for a specific app, feature, or campaign.
- Anti-taste: examples that clarify what to reject.

## Reference Hygiene

Do not collapse everything into "Indian aesthetic," "maximalism," or "cool futuristic UI." Name the actual mechanism: border rhythm, halftone grain, hand-painted lettering, archive grid, oxide palette, tile ornament, label hierarchy, print wear, technical annotation, control-panel grouping, mission telemetry, circuit-line routing, cinematic title hierarchy, or collage layering.
