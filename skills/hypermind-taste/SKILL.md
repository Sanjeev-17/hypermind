# Hypermind Taste

Use this skill as a taste operator: translate Sanjeev's visual instincts into concrete design choices while preserving usability.

## Operating Loop

1. Read the user's task and identify the product context: operational tool, consumer app, editorial page, brand surface, game, prototype, or review.
2. Apply the core taste lens below, then adapt intensity to the context. A dashboard can carry this taste through hierarchy, color, typography, texture, and micro-ornament without becoming a poster.
3. If visual direction is unclear or the user asks for inspiration, read `references/reference-search.md`.
4. If designing UI or reviewing implementation, read `references/ui-translation.md`.
5. If the task asks what the taste is, or a deeper art-direction rationale is useful, read `references/visual-language.md`.
6. If the user gives feedback about what they liked or disliked, update `references/taste-evolution.md` as evidence first. New feedback normally enters as an Observation with confidence and scope; promote it to Pattern only when reinforced, and to Principle only when stable or explicitly confirmed.

## Core Taste Lens

Favor work that feels collected, made, and lived-in: archival fragments, vernacular print energy, ornamental systems, tactile material, pattern density, patina, confident typography, and saturated accents.

Keep the output functional. Complexity should reward attention, not block scanning or task completion.

Overall priority: function, then hierarchy, then interaction, then expression.

## Design Heuristics

- Start with structure: strong layout, clear hierarchy, useful interaction states, and readable content.
- Add expressive detail through borders, dividers, badges, small panels, background texture, illustration, typographic contrast, and meaningful pattern.
- Use color with confidence: oxide red, turmeric yellow, indigo, ultramarine, teal, faded cream, charcoal, and occasional hot pink or electric blue. Avoid a single-hue UI.
- Prefer tactile imperfection over sterile polish: print grain, worn edges, halftone, paper, tile, metal, ceramic, packaging, signage, and handmade marks.
- Let type carry character: editorial scale shifts, condensed display faces, vernacular label logic, strong numerals, and crisp supporting text.
- Use ornament as system, not garnish. Patterns should reinforce navigation, grouping, identity, or rhythm.

## Avoid

- Generic SaaS minimalism, soft startup gradients, stock-photo blandness, glassmorphism as default, excessive rounded cards, decorative blobs, and empty luxury.
- Flattening cultural references into vague "ethnic" styling. Be specific about source qualities and respectful in use.
- Dense visuals that obscure affordances, states, labels, or content.

## Validation

Before finishing a design or review, check:

- Does the UI still work quickly for its real user?
- Is hierarchy clear before expressive surface detail is added?
- Is there at least one specific visual idea beyond generic polish?
- Are color, type, texture, and spacing acting together rather than competing?
- Are experimental details preserved where they create energy?
- Have redundant motifs, repeated instructions, or decorative noise been trimmed?
